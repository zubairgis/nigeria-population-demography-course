# Repository status

This is a **starter repository foundation only**.

As of 2026-09-30:
- no nationwide third-party dataset has been downloaded into this package;
- no nationwide processing has been completed;
- no data have been uploaded to GitHub;
- the proposed pilot is Bayelsa State / Sagbama LGA, but the pilot has **not yet been validated**;
- entries marked `UNRESOLVED` in the manifest must be resolved before public redistribution or national packaging.

The purpose of this starter is to make the next step reproducible: acquire verified source data, validate schemas/licences, build one real pilot, and only then scale nationally.
