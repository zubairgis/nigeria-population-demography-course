Interstate Border Settlement Analysis — 5 km Corridor

A practical geospatial exercise for examining settlements, accessibility, infrastructure and service conditions along shared State/FCT borders in Nigeria.

Purpose of the Task

Select two neighbouring Nigerian States/FCTs and examine the settlements located within 5 km on both sides of their shared border.

The analysis identifies the LGAs that directly share the interstate boundary, maps each border LGA separately, and creates synchronized settlement-number tables for further analysis in Excel.

The webpage does not display programming code. The analysis engine runs in Google Colab using the validated datasets stored in the course GitHub repository.

Study Area Logic

SelectionTwo neighbouring States/FCTs
Border zone5 km inside each State/FCT
Administrative focusOnly LGAs that actually touch the shared border
Settlement sourceGRID3 Nigeria Settlement Extents
Context layersRoads, bridges, drainage, places and health facilities
Final productsPNG maps, CSV tables and ZIP package

3

4

Identify Border Settlements

Extract settlement components located inside the corridor.

5

6

Assign settlement numbers within each border LGA and retain the same numbers in Excel-ready tables.

7

Create one border overview plus one detailed panel for each border-sharing LGA.

Map Design

Dynamic LGA Panels

CSV Variables for Excel Analysis

The main settlement CSV is synchronized with the settlement numbers shown on the map. It can be used for further analysis, sorting, filtering and development-planning exercises.

VariableUse
LGA settlement numberDirectly matches the number displayed in the corresponding LGA map panel.
State/FCT and LGAIdentifies the administrative side of the interstate border.
Settlement nameRetained in the CSV even though settlement-name labels are not shown on the map.
Settlement typeHelps distinguish different settlement forms.
Building countProvides an indicator of settlement size and built-up intensity.
Distance to shared borderMeasures how close the settlement is to the interstate boundary.
Nearest health facility and distanceSupports basic service-accessibility assessment.
Longitude and latitudeAllows settlement points to be reused in other mapping or field-planning applications.
