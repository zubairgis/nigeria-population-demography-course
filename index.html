Interstate Border Settlement Analysis

Select two neighbouring Nigerian States/FCTs, run the analysis in Google Colab, and receive border-LGA maps and synchronized CSV results.

Step 1

Select the two States/FCTs

View Data Repository
Select two neighbouring States/FCTs. The default example is Bayelsa–Delta.
Step 2

Run the analysis

1. Colab opens
Your selected States/FCTs are passed to the notebook automatically.
2. Choose Runtime → Run all
The notebook verifies the shared border and processes the 5 km corridor.
3. Receive results
At the end, the notebook creates and downloads the ZIP package automatically.
Outputs

What you will receive

  • One shared-border overview map showing clipped border-sharing LGAs, LGA labels, roads, and rivers/streams.
  • One detailed panel for each LGA that shares the interstate border.
  • Settlement numbers synchronized with the Excel/CSV tables.
  • Roads, drainage, bridges, and place-name labels at LGA level.
  • Interstate settlement CSV, LGA summary CSV, State summary CSV, and separate CSV for each border LGA.
  • PNG maps and a final ZIP package.
Important: GitHub Pages is the student launcher. The geospatial processing itself runs in Google Colab because the analysis uses large spatial datasets and Python geoprocessing libraries.
